## Scope

API 14A supplement to ES-M0009B (Inconel Alloy X-750, UNS N07750). This specification adds requirements for materials used in API 14A (SSSV) products. All requirements of ES-M0009B apply; this supplement defines additional acceptance criteria per API Specification 14A.

## Base Specification

ES-M0009B — X-750 Inconel Spring. All chemical composition, heat treatment condition, mechanical property, and receiving requirements per the base specification.

## Melt Practice

Material shall be produced by one of the following melting methods:

- Vacuum Induction Melting + Vacuum Arc Remelting (VIM+VAR) — standard
- Vacuum Induction Melting + Electroslag Remelting (VIM+ESR)
- Vacuum Induction Melting (VIM) — acceptable for wire < 0.250" diameter

The MTR shall state the melt practice used.

## Heat Treatment Process

Heat treatment shall be performed per SP.003 and shall conform with the supplier's/manufacturer's documented specification.

## Receiving

In addition to ES-M0009B receiving requirements, the MTR shall include a statement of melt practice.
