## Scope

API 14A supplement to ES-M0009A (Alloy 718, UNS N07718). This specification adds requirements for materials used in API 14A (SSSV) products. All requirements of ES-M0009A apply; this supplement defines additional acceptance criteria per API Specification 14A.

## Base Specification

ES-M0009A — Nickel Chrome Alloy 718. All chemical composition, heat treatment condition, mechanical property, and receiving requirements per the base specification.

## Melt Practice

Material shall be produced by one of the following melting methods:

- Vacuum Induction Melting + Electroslag Remelting + Vacuum Arc Remelting (VIM+ESR+VAR) — standard for critical/HPHT components
- Vacuum Induction Melting + Vacuum Arc Remelting (VIM+VAR)
- Vacuum Induction Melting + Electroslag Remelting (VIM+ESR)

The MTR shall state the melt practice used.

## Heat Treatment Process

Heat treatment shall be performed per SP.003 and shall conform with the supplier's/manufacturer's documented specification.

## Receiving

In addition to ES-M0009A receiving requirements, the MTR shall include a statement of melt practice.
