## Scope

API 14A supplement to ES-M0009D (Alloy 925, UNS N09925). This specification adds requirements for materials used in API 14A (SSSV) products. All requirements of ES-M0009D apply; this supplement defines additional acceptance criteria per API Specification 14A.

## Base Specification

ES-M0009D — Nickel Chrome Alloy 925. All chemical composition, heat treatment condition, mechanical property, and receiving requirements per the base specification.

## Melt Practice

Material shall be produced by one of the following melting methods:

- Vacuum Induction Melting + Vacuum Arc Remelting (VIM+VAR) — standard
- Vacuum Induction Melting + Electroslag Remelting (VIM+ESR)

The MTR shall state the melt practice used.

## Heat Treatment Process

Heat treatment shall be performed per SP.003 and shall conform with the supplier's/manufacturer's documented specification.

## Receiving

In addition to ES-M0009D receiving requirements, the MTR shall include a statement of melt practice.
